## 1. Method

Branch coverage was measured with coverage.py in branch mode (`--cov-branch`). Every decision point (`if`, `for`, `while`, `try`, conditional expressions) has two or more possible outcomes, and a branch is covered when the test suite takes that outcome at least once. This is a stricter measure than statement coverage. Test files and tooling are excluded.
